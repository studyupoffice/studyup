STUDYUP — SITE CORE + ARHIVA BAC
=================================

Acest pachet contine:
- index.html — pagina principala
- teste-bac.html — interfata completa de filtrare a arhivei BAC
- surse-si-drepturi.html — baza pentru pagina de transparenta juridica
- assets/studyup-logo.png — logo-ul ales de StudyUp
- data/catalog-bac.js + JSON + CSV — catalogul pentru 3394 PDF-uri

IMPORTANT: PDF-urile nu sunt incluse in CORE, pentru a pastra pachetul mic.
Pentru ca butoanele Subiect/Barem sa functioneze, combina in radacina repository-ului folderele bac/ din cele 9 pachete STUDYUP-BAC.
Structura finala trebuie sa fie:
  index.html
  teste-bac.html
  surse-si-drepturi.html
  assets/
  data/
  bac/
    2012/
    ...
    2026/

NU urca ZIP-urile ca ZIP in GitHub Pages. Dezarhiveaza fiecare pachet si combina folderul bac/ in acelasi bac/.
Pentru mii de fisiere, GitHub Desktop este mult mai potrivit decat Upload files din browser.

Nota juridica: textele incluse nu garanteaza automat dreptul de republicare pentru orice document. Pastreaza anteturile/sursele documentelor oficiale si verifica regimul aplicabil inainte de lansarea comerciala.
